# Code Review Guidelines (default)

These guidelines apply to every language. Language-specific files
(`code-review.<language>.md`) are appended below this file and may override or
extend these rules.

- Focus on correctness first, then readability, then style.
- Flag potential bugs, unhandled edge cases, and security issues.
- Prefer suggesting concrete corrected code over vague advice.
- Call out dead code, misleading names, and duplication.
